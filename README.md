# Juego de carreras (167 niveles + torneo + PvP)

Incluye 3 modos de juego:

- **Arcade 167 niveles**: tráfico, obstáculos, cajas sorpresa y nitro recogible de 5s.
- **Torneo vs IA**: ahora se juega con el **mismo estilo arcade** (misma base de conducción y obstáculos), añadiendo **mini mapa** de objetivo.
- **PvP local**: mismo estilo arcade, también con **mini mapa** para ver lo que toca hacer.

## Controles

- Flechas izquierda/derecha
- A/D también funcionan para mover

## Ejecutar

```bash
python3 -m http.server 8000
```

Abre `http://localhost:8000`.
